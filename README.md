### Ключевые проекты:

**1. ML-пайплайн для персонализированных акций (2+ млн клиентов)**  
Построил end-to-end ML-систему, которая каждый месяц генерирует персональные рекомендации для 2+ млн клиентов. Собираю признаки за 12 месяцев из ClickHouse, обучаю CatBoost на GPU (20+ категориальных признаков, классовый дисбаланс), делаю инференс чанками по 100k клиентов, интегрирую через API. Результат: охват вырос с 65% до 99.2%, вовлечённость — с 0.81% до 7.51% (+827%), время подготовки акций — с 3 дней до 45 минут.

**2. ETL-пайплайн для акции с начислением купонов**  
Разрабатываю скрипты для акций с механикой "шансов" для розыгрышей: полный цикл от загрузки данных участников до отправки купонов через API. Выгружаю данные из ClickHouse и OLAP-куба, рассчитываю количество купонов по условиям (сумма чека ≥ 800 ₽, франшизы — 3+ покупок в неделю), генерирую уникальные номера, отправляю на API сайта. Создаю отчёты в Excel и JSON для маркетинга.

**3. Система анализа эффективности маркетинговых кампаний**  
Построил на Python инструмент для оценки эффективности Push и Email-рассылок. Интегрируюсь с API и ClickHouse, формирую целевые и контрольные группы (алгоритм подбирает похожих клиентов, не участвовавших в кампании), считаю метрики (сумма транзакций, бонусы, количество чеков) за 7 и 30 дней. Генерирую CSV-отчёты для аналитиков.

**4. Data Reconciliation: сопоставление банковских транзакций**  
Разработал алгоритм сопоставления транзакций между банком и внутренней БД (без общего ключа). Нормализовал 40+ названий магазинов, реализовал слияние по формату и сумме, вычислил разницу во времени в минутах, оставил только ближайшую по времени транзакцию. Точность выросла с 60% до 95%, время обработки — с 4 часов до 5–10 минут.
